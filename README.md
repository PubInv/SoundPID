# SoundPID
## Project #88: Improved API and dimensional Analysis of a PID controller

This is an attempt to reconsider PID controllers to provide a sound dimensional analysis.
This is not new, but is rarely documented. 

Many of the existing PID APIs do not make the depence on the sampling time explicit, which 
is a very confusing deficit.

This can be more an effort to do proper documentation than a serious programming project;
nonetheless, we may extend common PID controllers and create sample code and test cases as 
examples.
